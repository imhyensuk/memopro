# 0166. E037b 사전 등록: `budget`이 단계 전체를 덮는가 — 512토큰, 3B·7B, 예산 + 256MiB

- **날짜**: 2026-10-05
- **유형**: experiment (사전 등록)
- **상태**: 확정. 실행 전
- **관련 기록**: 0165 (제작), 0164 (E037), 0163 (E037 사전 등록)

## 설계

- E037과 같다: `memopro.finetune(seq_len=512)`, E037의 글 5개, 경우마다 새 프로세스, 스왑 오염 규칙. 실행기는 워터마크를 넣지 않는다. 기준 footprint는 import 뒤·MPS 시작 전에 잰다.
- **경우**

| 이름 | 모델 | 예산 | 역할 |
|---|---|---|---|
| T3a | 3B | 1GiB | 학습 |
| T3b | 3B | 768MiB | 학습 |
| T7a | 7B | 2.5GiB | 학습 |
| T7b | 7B | 2GiB | 학습 |
| R7 | 7B | 1.5GiB | 거절되어야 함 |

- 7B 예산을 E037(2GiB, 1.5GiB)에서 2.5GiB·2GiB로 바꿨다. 이제 예산이 활성값까지 덮으므로, 1.5GiB는 가장 큰 가중치(1,039MiB) + 활성값을 담을 수 없다(0165). 그래서 그 경우는 거절(R7)을 확인한다.
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e037b_step_budget.run --all`. 결과는 `docs/research/data/e037b/`.

## 기준

| # | 기준 |
|---|---|
| **K1** | 학습 네 경우 모두 512토큰 × 5단계 완주 |
| **K2** | 모델마다 두 예산의 손실이 유한하고 비트 동일 |
| **K3** | 학습 네 경우 footprint 증가 ≤ **예산 + 256MiB**(E037은 + 512MiB), 스왑 증가 ≤ 64MiB(오염 규칙 뒤), 런타임 최대 계상 ≤ 원래 한도 |
| **K4** | R7은 `BudgetExceeded`로 거절(학습을 시작하지 않음) |

- 실패하면 멈추고 보고한다.

## 논문 매핑

- **Evaluation (보장된 상한)**: 프로세스 전체가 사용자의 예산 + 작은 상수 안에 있는지. 상한을 지킬 수 없는 설정의 거절.
