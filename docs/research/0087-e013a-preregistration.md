# 0087. E013a 사전 등록: γ의 압박 신호(macOS 압박 수준)는 사용자가 느끼는 압박을 가리키는가

- **날짜**: 2026-09-29
- **유형**: experiment (사전 등록)
- **상태**: 확정 (결과는 다음 기록)
- **관련 기록**: 0052 E6 (γ 설계), 0053 (이 Mac의 압박 수준이 계속 "경고"였음, 수준별 예산 계수의 실측 보정 필요 → E013의 첫 질문), 0051 (기준선), 0077 (E017c Q1: 1초 이상 구간의 스왑 증가량 신호), 0014·0062 (E014 쾌적 기준 24.1ms)

## 배경

> "E013 진행해"

- γ(`memopro.elastic`)는 macOS에서 `kern.memorystatus_vm_pressure_level`(1 정상, 2 경고, 4 위험)을 읽는다.
  - 경고면 `load` 예산을 절반으로, 위험이면 4분의 1로 줄인다.
  - 셀 경계와 `train_session` 스텝 경계에서도 이 수준에 따라 조치한다.
  - `memopro run`은 γ를 기본으로 켠다.
- 0053에서 이 Mac은 평온해 보여도 계속 "경고"였다. E017도 같은 관찰을 했다(0073 §1).
- 오늘(2026-09-29) 확인한 값은 1(정상)이었다. 스왑 2.9GB 사용, 보수적 가용량 2.37GB였다.
- **신호가 틀리면 γ의 모든 조치가 틀린다.** 그래서 E013을 둘로 나눈다.
  - **E013a**: 신호 보정(이 기록).
  - **E013b**: 조치의 효과. E013a 결과를 보고 따로 사전 등록한다.

## 1. 측정 (`experiments/e013_gamma/signal.py`)

- **1초마다 기록**
  - macOS 압박 수준(`memopro.elastic.current()`).
  - 시스템 스왑 사용량(sysctl).
  - memopro 보수적 가용량과 OS 추정 가용량(`doctor`).
  - E014 반응성 탐침에서 그 1초 동안 가장 느린 읽기(ms). 탐침은 256MiB, 250ms마다 페이지를 읽는다.
- **일정** (2회 반복)
  - 평온 60초.
  - 이어서 P = 1, 2, 3, 4GiB마다: E011 압박 프로세스가 무작위 데이터 P를 60초 쥔다 → 놓고 30초.
  - 마지막에 평온 30초. 전체 약 15분이다.
- SSD 쓰기 바이트(ioreg)를 전후로 기록한다(0078 뒤의 SSD 수명 논의).
- **명령**:

  ```
  caffeinate -is .venv/bin/python -m experiments.e013_gamma.signal --rounds 2
  ```

  분석: `.venv/bin/python -m experiments.e013_gamma.analyze`. 결과는 `docs/research/data/e013/signal.json`, `summary_signal.json`, `env_signal.json`.

## 2. 기준 사실(ground truth)

- **해로운 1초**: 그 1초에 탐침의 가장 느린 읽기가 24.1ms를 넘는다(E014 쾌적 기준). 사용자가 끊김을 느끼는 대리 지표다.
- **에피소드**: 해로운 1초들을 2초 이내 간격까지 묶은 구간.
- **평온한 1초**: 앞뒤 5초 안에 해로운 1초가 없다.

## 3. 후보 신호와 판정 (실행 전 고정)

- **후보 신호** (1초마다 켜짐/꺼짐)

| 신호 | 정의 |
|---|---|
| L | macOS 수준 ≥ 경고(2): **γ의 현재 신호** |
| S | 직전 1초 동안의 시스템 스왑 증가 ≥ 64MB (E017c Q1) |
| A | memopro 보수적 가용량 < 전체의 10% |
| K | OS 추정 가용량 < 전체의 10% |
| S∨L | S 또는 L |

- **지표**
  - **민감도**: 에피소드 가운데, 시작 2초 전부터 끝 2초 뒤 사이에 신호가 한 번이라도 켜진 비율.
  - **특이도**: 평온한 1초 가운데 신호가 꺼져 있던 비율.
  - 보고만: 평온 단계(`calm`)에서 켜진 비율(γ가 예산을 헛되이 줄이는 비율), 압박 시작 뒤 처음 켜질 때까지의 초.
- **쓸 만함** = 민감도 ≥ 0.8 **그리고** 특이도 ≥ 0.9. 에피소드가 5개 미만이면 민감도는 판정하지 않는다.
- **결론 규칙**
  1. L이 쓸 만하면: γ의 신호를 유지하고 E013b(조치 효과)로 간다.
  2. L은 안 되지만 다른 후보가 쓸 만하면: γ의 macOS 신호를 가장 좋은 후보로 바꾸는 결정 기록을 연다(사용자 결정). E013b는 그 신호로 한다.
  3. 아무것도 안 되면: γ를 실험 기능으로 표시한다. macOS에서 `memopro run`의 γ 기본값을 끄는 결정 기록을 연다(사용자 결정).
  - 추가로, L의 평온 단계 켜짐 비율이 10%를 넘으면 규칙 1이더라도 "경고 = 예산 절반" 계수를 다시 보자고 제안한다.

## 한계 (미리 적어 둠)

- 탐침은 한 가지 작업(256MiB 페이지 읽기)이다. 해로움을 대신 재는 지표일 뿐이다.
- 압박은 한 가지(무작위 데이터를 쥔 프로세스)다. 실제 앱(브라우저 등)의 압박과 다를 수 있다.
- 기기 1대(M1 8GB, macOS). Linux PSI 기준은 이 실험에서 보정하지 않는다.
- 압박 단계에서 기기가 끊기고, OS 스왑으로 SSD 쓰기가 생긴다(몇 GB 예상).
