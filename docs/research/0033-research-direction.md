## 논문 A 계획

**가제**: "학습 중 메모리는 얼마나 낭비되는가: 학습 상태의 종류별 정보량 측정"

| RQ | 질문 | 기존 근거 |
|---|---|---|
| RQ-A1 | 학습 상태(가중치·그래디언트·옵티마이저 모멘트·저장 활성값)는 종류별로 실제 몇 비트가 필요한가? 무손실 기준과 학습 영향 기준으로 각각 본다 | E005 (GPT-2 small) |
| RQ-A2 | 그 낭비는 모델 크기, 학습 단계, 정밀도(fp32·bf16), 옵티마이저, 과제(처음부터 학습·파인튜닝)에 따라 어떻게 달라지는가? | 없음 |
| RQ-A3 | OS의 범용 메모리 압축은 이 낭비를 얼마나 회수하는가? | E005: 1.00배 |
| RQ-A4 | 낭비와 민감도는 어디에 몰려 있는가? (이상치, 거대 활성값, LayerNorm 관련 텐서) | E002·E003 |
| 논의 | 원리적으로 그럴듯한 기법(α)은 왜 실패했는가? (Kim 2021의 이론 예측과 실측) | E001~E003 |

- **예정 실험 E012** (확장 센서스 측정). census 정밀 경량판이 완성된 뒤 사전 등록한다.
  - 모델: GPT-2 small·medium, Pythia 160M·410M, 작은 ViT, 가능하면 작은 확산 모델
  - 학습 단계: 처음부터 학습(초기·중기·후기), 파인튜닝
  - 정밀도: fp32, bf16 혼합
  - 옵티마이저: AdamW, SGD, (선택) Muon
  - 환경: M1 8GB(작은 모델), 외부 GPU(큰 모델)
- **예상 기여**
  - 학습 상태를 종류별로 체계적으로 측정한 결과(조사 범위에서 같은 연구를 찾지 못함, 0029 D21)
  - 측정 도구(census)와 데이터 공개
  - 메모리 절감 기법 설계 지침(K1~K4)
- **구분해야 할 선행 연구**: ZipNN, DFloat11, Heilper & Singer 2025(가중치·체크포인트·KV 중심), AIMET·HAWQ(추론 양자화 민감도).
