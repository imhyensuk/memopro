## 해석

- **예산이 학습 단계 전체를 덮는다는 것을 2,048토큰(3B)과 표본 밖 점(7B 1,024토큰)에서 확인했다.**
  - 덜어 둔 몫이 첫 단계 뒤 측정으로 올라가지 않았다. 측정값이 1.4배 추정 안에 들었다는 뜻이다.
  - 7B 1,024토큰은 0187의 배수를 정할 때 쓰지 않은 점이다.
- **시작 전 거절이 동작한다.** 7B 2,048토큰은 3.75GiB에서 첫 단계 전에 거절됐다. E041에서는 첫 단계를 계산한 뒤에 거절됐다.
- **생성**: 두 경우 모두 출력이 같고 footprint가 예산 + 256MiB 안이다. G3는 스왑 기준도 통과했다.
- **G7 스왑은 연구자의 잘못일 가능성이 높다.**
  - G7의 두 시도(19:18~19:23)와 같은 시간에, 이 기기에서 Rust 빌드와 정적 검사(`cargo clippy`, Linux 교차 검사 시도 포함)를 돌렸다. 0189 제작 중이었다.
  - 사전 등록 규칙으로는 실패이고, 판정을 바꾸지 않는다. 같은 측정 중에 다른 무거운 일을 하지 않는다는 원칙(0085의 MPS 교훈과 같은 종류)을 어겼다.
