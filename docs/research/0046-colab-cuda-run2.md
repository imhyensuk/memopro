## 새로 관찰한 점

- **`source` 동면도 호스트 RAM이 약 18.9MB 늘었다**(498MB 모델 대비 약 4%). 동면할 때 GPU 텐서를 CPU로 복사해 원본 파일과 비교하는데(0036 B3), 이 임시 사본을 CPU 할당자가 곧바로 OS에 돌려주지 않는 것으로 보인다. F1 수정 덕분에 이 비용이 보고에 드러났다.
- **개선 후보(알파 이후)**: GPU에서 다이제스트를 계산하거나, 원본 파일 영역을 청크 단위로 비교해 임시 사본을 줄인다. 채택 여부는 별도 결정이 필요하다.
- CUDA 예약 메모리 감소는 1차 511.7MB, 2차 532.7MB로 할당자 상태에 따라 달라졌다. 두 번 모두 파라미터 크기(497.8MB) 이상이다.
