- **그대로**

  - 경우(P/S15/S3), 프롬프트 4개 × 64토큰, 환경 변수, 새 프로세스, 오염 규칙, 판정 코드, 기준 X1·X2·X3.
- **바뀐 것**
  - 실행기 `experiments/e033c_spec_decode_quiet/run.py`. E033b와의 차이는 결과 경로와 문서 문자열뿐이다.
  - **시스템 조건**: 사용자가 실행 전에 다른 앱을 닫는다. Claude 앱은 Claude Code가 돌아가는 곳이라 남는다.
  - 시작 때 스왑과 메모리 상태는 `env.json`의 `swap_at_start`와 결과 기록에 남긴다.

## 기준 (E033·E033b와 같다)

| # | 기준 |
|---|---|
| **X1** 출력 동일 | 4개 프롬프트 모두 S15의 64토큰이 P와 같다 |
| **X2** 속도 | S15 토큰당 시간 ≤ P의 1/2.5 |
| **X3** 메모리 | S15 footprint 증가 ≤ 예산 + 초안 + 512MiB 그리고 ≤ 2,943MiB, 시스템 스왑 증가 ≤ 64MiB(오염 규칙 뒤), 런타임 최대 계상 ≤ 한도 |

- 관문 G4-E4 = X1·X2·X3. 실패하면 멈추고 보고한다.
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e033c_spec_decode_quiet.run --all`. 결과는 `docs/research/data/e033c/`.
