## 3. 성능 (실측)

### 3.1 CUDA (Colab T4, 0045~0056)

| 항목 | 결과 |
|---|---|
| 7B 불러오기 | Qwen2.5-7B int8, 최대 8.97GB(예산 13.89GB) |
| 제한된 GPU에서 학습 | 실제 OOM 한도에서 완주. SGD 파라미터 차이 1.58e-7. accelerate와 달리 유효 배치 유지 |
| `check` | 학습 −0.2~−1.2%, 추론 +5%. accelerate보다 6/6 정확 |
| β | CUDA 512MB 회수, 비트 동일. 가드·GPT-2·compile 25/25 |

### 3.2 이 기기 (M1 8GB, 스왑 5~10GB 사용 중)

| 항목 | memopro 없이 | memopro | 기록 |
|---|---|---|---|
| GPT-2 학습(배치 8×512, MPS) | 0/3, MPS OOM | **3/3 완주**, 스텝 6.4s | 0063 |
| 1.5B 두 인스턴스 번갈아 쓰기 | 둘 다 올려 두기는 중단(> 600s) | **β 99s**(다시 불러오기 110s), 출력 동일 | 0063 |
| 쉬던 모델 복귀 | OS 스왑에서 3.9s(CPU)·3.2s(MPS) | **β 1.3s·1.4s**, 비트 동일 | 0060 |
| 1.5B 추론(같은 bf16 구성) | 불러오기 10.1s, 스왑 +3.2GB, 탐침 p95 202ms | 불러오기 **4.1s**, 스왑 **+0.9GB**, 탐침 **61ms**, 속도 11.5 tok/s(`naive` 11.0) | 0063 |
| 해제한 CPU 메모리 반환 | `del model`도 0%(libmalloc 캐시) | 캐시를 끄면 **0.965**(`memopro run`은 자동) | 0063 |
| fp32 파라미터 압축률 | macOS식 페이지 LZ4 1.00 | memopro 0.84 | 0060 |

### 3.3 한계로 확인된 것

- 8GB에서 1.5B·3B 추론은 **어떤 설정도 쾌적 기준(C2)을 만족하지 못했다**(0063).
- 기본 설정은 두 모델을 거부했다. 지금은 될 설정을 안내한다(0064).
- MPS에서 해제한 메모리는 그래픽 드라이버(IOAccelerator)가 압박이 올 때까지 붙잡는다(0062 §1).
- 모델 계열(GPT-2·Qwen)과 GPU(T4)의 범위가 좁다.

## 4. 기능

| 영역 | 기능 |
|---|---|
| 환경·예산 | `doctor`. 예산: `auto`, 크기, 비율, `-2GB`(남기기), `2GB..6GB`(범위, 최소 미달 시 멈춤), `6GB!`(강제), 풀별(장치·호스트·디스크), `{use,min,max}`. `budget_basis`, 크기 여유분, `using()` |
| 접근 계층 | `load`(메타데이터로 크기 계산, 원래 형식·반정밀도·int8·int4·오프로드, 장치에 바로 올림, 실패하면 다음 구성), `check`(할당 없는 예측), `optimize`, `train_session`(정확한 마이크로배치·OOM 재시도·체크포인팅·활성값 오프로드·혼합 정밀도) |
| 들어갈 구성이 없을 때 | 검증된 설정 제안과 스왑 예상량(D-a, `BudgetExceeded.suggestions`, `check`·`optimize`·`run`에도), `fallback="stored"`(D-d) |
| β 동면 | `source`(조각 단위 대조) → `host` → `compress` → `spill`(동의 필요). 가드, torch.compile, 노트북 매직, macOS 캐시 안내 |
| census | 빠른·경량·정밀 모드, 권고, HF·Lightning 콜백 |
| γ와 실행 | 압박 신호(macOS·PSI), 안전 지점에서만 조치, `memopro run`(macOS에서 `MallocLargeCache=0`으로 재시작) |
| 공통 | 부작용 없는 import, `MemoproError` 계층, `report()` |

## 5. 평가

- **확인된 가치**
  - OOM으로 불가능하던 학습을 결과를 바꾸지 않고 가능하게 한다.
  - 여러 모델을 한 커널에서 쓸 때 멈춤을 막는다.
  - 메모리를 할당 없이 예측한다.
  - 같은 구성을 더 가볍게 불러온다.
- **확인되지 않은 가치**
  - 8GB에서 큰 모델 추론의 쾌적함
  - 외부 사용자에게의 이득(E010)
  - γ의 효과(E013)
- 다음 방향(쾌적함을 위한 방법론)은 0066에서 세운다.
