# 0092. Colab 7차 노트북을 파트별 파일 3개로 분리

- **날짜**: 2026-09-29
- **유형**: tool (사용자 요청)
- **상태**: 확정
- **관련 기록**: 0091 (E021 사전 등록과 통합 노트북)

## 요청

> "지금 현재 통합 셀로 제작해둔 구글 코랩 실험 코드를 각 파트별로 분리해줘. 예를 들어, 로컬 모델 구동 실험, 학습 및 개발 실험 등으로 나눠서 여러 개의 통합 셀 파일로 나눠줘."

- 사용자가 준 `~/Downloads/colab_t4_heavy.ipynb`는 저장소의 노트북과 셀 7개가 모두 같았다(출력 없음). 그래서 저장소 원본에서 나눴다.

## 바뀐 것

- `examples/colab_t4_heavy.ipynb`(셀 3개)를 지우고, 파트마다 노트북 하나씩 만들었다.

  | 파일 | 파트 | 구성 |
  |---|---|---|
  | `examples/colab_t4_train.ipynb` | ① 학습·개발 과정 | 안내 + 통합 코드 셀 1개 |
  | `examples/colab_t4_infer.ipynb` | ② 로컬 AI 모델 구동 | 안내 + 통합 코드 셀 1개 |
  | `examples/colab_t4_multi.ipynb` | ③ 여러 모델·프로세스 수준 기능 | 안내 + 통합 코드 셀 1개 |

- 각 안내에는 그 파트의 측정 내용, 예상 시간, 0091의 판정 기준, 공통 준비(T4, Drive `install/`, 결과 위치, 이어하기, 공정성)를 담았다.
- **코드 셀은 이전 통합 노트북의 해당 셀과 같다**(빌드 커밋을 적는 `EXPECTED_COMMIT` 줄만 다름). 스크립트로 비교해 확인했다.
  - 측정 방법, 설정 기본값, 결과 폴더 구조(`results/train|infer|multi/`)는 바뀌지 않았다. 그래서 0091의 사전 등록은 그대로 적용된다.
- `examples/colab_t4/build.py`가 세 파일을 만든다.
- `tests/test_colab_notebook.py`는 파일마다 코드 셀이 1개인지, 스스로 완결되는지, 워커가 컴파일되는지, 커밋된 노트북이 원본과 같은지 확인한다.
