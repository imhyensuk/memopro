## 설계 (E027과 같은 경우와 판정, 작업마다)

- GitHub Actions Linux 실행기(`e040.yml`, ubuntu-24.04, 수동 실행), Python 3.12, pandas·scikit-learn·scipy 최신판(버전은 `env.json`).
- 경우마다 cgroup 범위(`systemd-run --scope -p MemoryMax=L`).

| 경우 | 내용 |
|---|---|
| 1 | 그대로, 한도 없음 → 최대 RSS(피크)와 불러오기 뒤 RSS 측정 |
| 2 | 그대로, 한도 L = 피크/2, 스왑 없음 |
| 3 | `memopro run --transparent B`, 한도 L, 스왑 없음. **B = L − (경우 1의 불러오기 뒤 RSS + 64MiB)** |
| 4 | 그대로, 한도 L, 스왑 있음 (보고) |

- E027은 B = L − 192MiB였다. pandas·scikit-learn은 불러오기만으로 더 크므로 작업마다 잰 값을 쓴다(실행 전에 정한 규칙).
- **명령**: 작업 흐름 수동 실행(`gh workflow run e040.yml`). 결과는 `e040` 산출물 → `docs/research/data/e040/`.
