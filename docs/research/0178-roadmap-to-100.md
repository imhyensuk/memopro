# 0178. 100%까지의 로드맵: 영역별 완료 조건과 여섯 단계

- **날짜**: 2026-10-05
- **유형**: decision (제안, 사용자 승인 대기)
- **상태**: 제안
- **관련 기록**: 0176 (객관 평가 4, 약 58%), 0177 (논문 계획), 0148 (목표·성공 기준), 0156 (선택지 C: MLX), 0125 (G4 설계, E5)

## 요청

> "그럼 지금 라이브러리의 종합 완성도를 100% 달성하고자 한다면, 어떤 개선, 개발 방향을 가져야할지 로드맵을 세워."

## 먼저: "100%"의 정의

- 지금까지의 달성률은 연구자의 판단이었다. 100%를 목표로 하려면 **영역마다 측정 가능한 완료 조건**이 있어야 한다.
- 아래 표의 완료 조건을 모두 사전 등록 실험으로 통과하면 그 영역을 100%로 본다. 조건은 0148의 목표 문장에서 나왔고, 새 목표는 더하지 않았다.
- **혼자서는 닿을 수 없는 부분이 있다.** 외부 사용자, 16GB 기기, 동료의 E010 수집, 논문 게재는 사용자와 외부에 달려 있다. 각 항목에 표시했다.

## 순서: 여섯 단계

평가 비중 × 비용 × 의존성으로 정했다. 🙋는 사용자 몫이다.

| 단계 | 내용 | 올라가는 영역 | 예상 합계 |
|---|---|---|---|
| **1. 공개** | E1 배포(🙋), E2 설치 시험, 모델 호환 표 초안 | E | 약 62% |
| **2. 범위** | A1 모델 계열 2개 추가(내려받기 허락, 디스크 필요), A2 2,048토큰, A3 생성 예산 | A | 약 70% |
| **3. 논문** | D1 P1·P2·P4 초안. 2단계 결과가 P1을 강하게 함 | D | 약 73% |
| **4. 기기와 경쟁자** | A4 Colab T4에서 G4-C(Unsloth 감싸기) + A5 Unsloth 비교(🙋 Colab 실행), 16GB Mac(🙋 기기) | A | 약 79% |
| **5. 범용 런타임** | B1 작업 3개 추가, B2 macOS 명시적 연결, B3 예측 확장, B4 C 예제, C1·C2 | B, C | 약 88% |
| **6. 속도와 1.0** | A6(E5 무손실 압축, MLX 결정), E3·E4 문서·벤치, D2~D4 정리, E5·E6 사용자와 1.0 | 전부 | 약 95~100% |

- **마지막 5%는 외부에 달려 있다**: 외부 사용자(E5), 논문 게재(D1), 16GB 기기(A4). 이것들이 없어도 나머지를 모두 마치면 약 95%다.
- 각 단계는 지금까지처럼 사전 등록 → 실험 → 관문으로 진행한다. 관문이 실패하면 멈추고 보고한다.
