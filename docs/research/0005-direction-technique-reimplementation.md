# 0005. 방향 결정: 개별 기법 구현 노선 채택 (단, 신규성 있는 기법으로)

- **날짜**: 2026-09-24
- **유형**: decision
- **상태**: 확정 — 신규성 조건의 적용 범위를 연구 코어로 명확화(→ 0010)
- **관련 기록**: 0003 (플래너 노선 → 대체됨), 0004 (권고안 C' → 기각), 0006 (후속 탐색)

## 배경 / 동기

0004는 메모리 플래너(C')를 권고했으나, 프로젝트 책임자(사용자)는 **개별 메모리 절감 기법을 직접 구현하는 노선(0003의 선택지 A)**을 선택했다.
단, 조건을 붙였다:

> 초기 목표(G1–G3)와 방향성을 **다른 라이브러리·도구와 겹치지 않는, 신박하고 창의적인 방법**으로 이끌어낼 수 있는지 탐색할 것.

## 결정

- memopro는 메모리를 **직접 줄이는 기법**을 제공하는 라이브러리로 간다. (플래너 노선 0003/0004는 보류)
- 0004가 지적한 선택지 A의 약점("성숙한 도구의 재구현 → 차별성·학술 기여 낮음")을 피하기 위해,
  **기존 기법의 재구현이 아니라 조사 범위 내에서 선행 사례가 없는 메커니즘**을 찾는 탐색을 선행한다 → 0006.

## 근거 (사용자 판단의 해석)

- 플래너는 메모리를 직접 줄이지 않는다(0004 약점 1). 프로젝트명과 목표(G2: 더 작은 메모리에서 구동)에는 **직접 절감**이 더 부합한다.
- 신규 기법을 찾을 수 있다면, 선택지 A의 "절감 효과" 강점(0004 표: 4점)과 학술적 가치를 동시에 얻을 수 있다.

## 0004 평가표와의 관계

0004의 선택지 A 점수(11.5)는 "기존 기법 재구현"을 전제로 한 것이다. 0006의 신규 기법 후보는 별도로 재평가한다.
