## 진단: NaN의 원인 (스크래치 진단 실행들)

1. **둘째 backward에서 모든 LoRA 기울기가 NaN**이었다. 손실은 유한했다.
   - 같은 글을 처음부터 두 번 넣으면 체크포인팅을 켰을 때는 NaN이 없었고, 껐을 때는 있었다.
   - 이전 코드(9aa1fe6)에서도 같았다. 그러니 E2 변경 탓이 아니다.
   - 훅을 달면 사라지기도 했다. 타이밍과 상태에 따라 나타났다.
2. **2층 축소 7B**(실제 가중치, 같은 LoRA, 같은 입력, 3회 반복)
   - **memopro 없이 PyTorch MPS에 그대로 올려도** 둘째·셋째 반복에서 NaN이 났다(다른 실행에서는 모두 정상).
   - 실패할 때 기울기의 SHA-256(`3a044fd4a150`)은 memopro로 흘려 쓸 때와 같았다. 흘려 쓰기에서는 매번 났다.
   - → memopro가 아니라 PyTorch MPS의 문제다.
3. **NaN이 처음 생기는 곳**: 출력 머리 아래 은닉 상태로 들어오는 기울기다.
   - 조각마다, 체크포인트가 없어도 났다.
   - 무작위·실제 가중치로 떼어 낸 연산은 처음에는 정상이었다.
4. **재현 조건**: 큰 MPS 텐서(예: 64MiB × 8)를 만들었다 지운 뒤 행렬곱 입력을 할당하면 재현됐다.
   - `g[13 × K] @ W[K × N]`(bf16·fp16·fp32 모두)이 **K > 131,072 = 2^17**이고 K가 16,384의 배수가 아닐 때 NaN을 낸다. 지운 텐서의 값이 NaN·1·0 어느 것이어도 그랬다.
   - K = 131,072·147,456(16,384의 배수)이나 행이 1~2개면 정상이다.
   - Qwen2.5의 어휘(151,936, 152,064)는 이 범위다. 출력 머리의 backward(기울기 × 가중치)가 바로 이 행렬곱이다.
   - 1.5B·3B 모양(N = 1,536·2,048)에서도 재현된다.
5. **이전 결과의 유효성**: 결함은 조용히 틀린 값이 아니라 NaN으로 나타났다(남은 값이 0·1이어도 NaN). 손실이 끝까지 유한했던 E028c·E034·E035의 학습 결과는 영향을 받지 않은 것으로 판단한다.
6. **K3의 해석(판정은 바꾸지 않음)**
   - 이 실행기는 기준 footprint를 torch·transformers·peft를 불러오기 **전에** 쟀다. E028c는 불러온 뒤에 쟀다.
   - 불러오기는 351MiB, MPS 초기화는 11MiB다. 그만큼 빼면 L7a 약 +2,411MiB, L7b 약 +1,915MiB로 기준 안이다.
   - 하지만 L7a의 시스템 스왑 +2,001MiB는 그와 무관하게 기준을 넘는다.

## 우회책 (`python/memopro/rt/torch.py::causal_lm_loss`)

- MPS에서 출력 머리가 2^17행을 넘으면, 손실 조각의 head 호출을 `VOCAB_SLICE` = 65,536행씩 잘라 계산한다(`torch.cat`).
  - 로짓은 같다. 각 조각의 backward는 내부 차원이 ≤ 65,536이다.
  - 체크포인트가 backward 때 조각을 다시 실행해도 잘린 계산이 쓰이도록, 이 처리를 `part` 안에 두었다.
- **확인**
  - 축소 7B 재현에서 흘려 쓰기 2번 + PyTorch 그대로 1번, 각 3회 반복이 모두 유한했다.
  - **기울기 해시가 모두 같았다**(`37311d37fa4f`). 흘려 쓰기와 그냥 실행이 비트 단위로 같다.
- **시험**: `test_loss_never_multiplies_over_more_than_2_17_vocabulary_rows_on_mps`
  - 어휘 151,936의 작은 모델에서 손실 계산 중 어떤 `F.linear`도 2^17행을 넘는 가중치를 받지 않는다. 손실은 잘라도 같다.
  - 우회책을 끄면 실패하는 것을 확인했다.
- 결함은 PyTorch(2.14.0) 쪽이다. 외부에 보고하는 일은 사용자 몫이다(Claude Code는 외부에 글을 올리지 않는다).

## 논문 매핑

- **Evaluation (G4 S1)**: 8GB M1에서 7B 16비트 LoRA가 단계당 약 18초로 도는 것까지는 보였다. 정확성은 E036b에서 확인한다.
- **Threats/Lessons**: 프레임워크 GPU 커널의 결함(큰 내부 차원의 행렬곱)이 학습을 깨뜨린 사례다. 재현 조건, 우회책, 그리고 흘려 쓰기와 그냥 실행의 기울기가 비트 동일함을 확인했다.
