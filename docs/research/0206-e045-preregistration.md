# 0206. E045 사전 등록: `adopt`가 실제 작업에서 같은 결과로 예산을 지키는가 — 대화 6개의 KV 캐시, 데이터 세 묶음

- **날짜**: 2026-10-06
- **유형**: experiment (사전 등록)
- **상태**: 확정. 실행 전
- **관련 기록**: 0205 (`Runtime.adopt`), 0204 (E044: KV 무손실 약 0.67)

## 설계 (경우마다 새 프로세스, M1 8GB)

| 갈래 | 그대로(keep) | 맡김(adopt) |
|---|---|---|
| **K** Qwen2.5-1.5B-Instruct(MPS, bf16, 그냥 불러옴), 대화 6개(WikiText 1,500토큰씩)가 번갈아: 첫 차례 + 두 바퀴. 차례마다 20토큰을 붙이고 16토큰 탐욕 생성 | KV 캐시 여섯이 모두 MPS에 남음 | 차례가 끝나면 그 대화의 KV를 런타임에 맡기고, 다음 차례에 `with`로 꺼냄. 런타임 예산 **224MiB**(KV 원래 합 약 270MiB보다 작음) |
| **D** 데이터 세 묶음: 판매 열(정수·실수 224MiB), 16비트 영상 묶음(256MiB), float32 시뮬레이션 장면 128개(128MiB). 세 바퀴 동안 묶음마다 합·최대·최소 | 메모리에 그대로 | 묶음마다 맡기고 계산할 때만 `with`. 예산 **448MiB**(원래 합 608MiB보다 작음, 가장 큰 묶음 256MiB는 깨어 있을 때 들어감) |

- **명령**: `caffeinate -i .venv/bin/python -m experiments.e045_adopt.run --all`. 결과는 `docs/research/data/e045/`.

## 기준

| # | 기준 |
