# 0110. 결정: 런타임은 SSD에 쓰지 않는다(방출·파일 캐시 제외), RS7 해제, 1단계 작업·이름, 끝까지 자율 진행

- **날짜**: 2026-09-29
- **유형**: decision (사용자 승인)
- **상태**: 확정
- **관련 기록**: 0107 (목표), 0108 (선행 조사), 0109 (설계 초안), 0027 (RS1~RS8), 0032 (SSD 쓰기 기본 끔), 0087·0088 (압박 실험의 스왑 쓰기)

## 사용자 결정

> "우선 SSD 관련 부분을 제외하고 개발을 진행해도 괜찮을까?"
>
> "그대로 진행해. 대신에 이전에 지금까지 해왔던 것처럼 단계마다 기록 연구 남기는 것도 잊지마. 자동으로 SSD를 제외한 라이브러리 완성 끝까지 진행해."

## 결정 내용

| # | 결정 | 내용 |
|---|---|---|
| N1 | **SSD 쓰기 제외** | 런타임 C-R은 SSD에 쓰지 않는다. 다섯 행동 가운데 "SSD 이동(방출)"은 만들지 않고, half·int4 파일 캐시 쓰기(0072)도 런타임에서는 쓰지 않는다. 남는 네 행동은 두기, 무손실 압축(RAM), 원본 재읽기(SSD **읽기만**), 재계산이다. 필요해지면 새 결정과 동의(`disk_writes`)로 추가한다 |
| N2 | **실험도 SSD에 쓰지 않는다** | OS 스왑을 일으키는 기준선은 이 Mac에서 재지 않는다. 모든 실험은 실제 RAM 안에서 설계하고, 경우마다 스왑 사용량을 전후로 기록해 증가가 없음을 보인다. 새 데이터 파일도 만들지 않고, 이미 디스크에 있는 파일을 읽기만 한다 |
| N3 | **RS7 해제** | 런타임 서비스 스레드와 입출력 작업자는 GIL과 무관하게 돈다. 안전 규칙은 runtime.md의 R4·I2·I6이다: 사용 중인 버퍼는 옮기지 않고, 백그라운드는 런타임이 소유한 메모리만 만지며, 사용자 텐서 교체는 안전 지점에서만 한다. RS6(SIMD)·RS8(`gil_used = false`)은 계속 보류한다 |
| N4 | **1단계 대표 비AI 작업** | 큰 숫자 배열 파이프라인: 파일 → 변환 → 집계, 여러 번 반복 |
| N5 | **이름** | Python `memopro.rt`, Rust `memopro::rt`, C 접두사 `mp_` |
| N6 | **자율 진행** | 1단계부터 끝까지 이어서 진행한다. 단계마다 연구 기록을 남긴다. 사전 등록한 관문이 실패하면 멈추고 원인과 선택지를 보고한다. 테스트가 통과한 PR은 직접 병합한다 |

## 이 결정이 설계에 주는 영향

- **runtime.md 초안 v0.1 → v0.2**
  - `Spilled` 상태를 뺀다(설계 기록으로만 남김).
  - 되돌릴 길이 원본·계보·압축뿐이다. 원본도 계보도 없는 데이터(예: 학습 중 계속 바뀌는 옵티마이저 상태)는 압축으로만 줄일 수 있다. 압축으로도 모자라면 "이 예산으로는 불가능"이라고 알린다.
- **원본 재읽기는 페이지 캐시를 쓰지 않는다**(macOS `F_NOCACHE`, Linux `POSIX_FADV_DONTNEED`). 페이지 캐시도 물리 RAM이므로, 런타임 때문에 쓰는 메모리 전체를 예산 안에 묶기 위해서다.
- **관문의 비교 대상이 바뀐다**
  - OS 스왑과 Dask(디스크 방출)는 SSD에 쓰므로 뺀다. Dask는 설치(다운로드)도 필요하다.
  - 대신 넣는 것: (a) 메모리가 충분할 때의 단순 실행(naive), (b) 사람이 짠 스트리밍 코드, (c) `numpy.memmap`(OS 페이지 캐시에 맡김).
- **2단계 학습 관문의 범위**: SSD 없이 무손실로 파라미터 초과 학습을 1/4 메모리에서 하는 것은 원리상 어렵다. 가중치는 학습 중 바뀌어 원본이 무효가 되고, 옵티마이저 상태는 압축률이 낮기 때문이다. 2단계 사전 등록 때 이 한계를 명시하고 범위를 정한다.
- **다운로드 없음**: 새 모델·패키지·크레이트는 받지 않는다. 필요하면 멈추고 허락을 받는다. 그래서 7B 대신 로컬에 있는 Qwen2.5-1.5B·3B와 GPT-2를 쓴다.

## 논문 매핑

- **주 논문 Design/Threats**: 쓰기 없는(write-free) 메모리 계층이라는 설계 제약과 그 근거(SSD 수명, 개인 기기). 원본 재읽기·재계산·압축만으로 얼마나 가는지가 평가의 한 축이 된다.
