# 0001. 프로젝트 착수: 비전과 목표

- **날짜**: 2026-09-24
- **유형**: milestone
- **상태**: 확정
- **관련 기록**: 0002, 0003

## 배경 / 동기

딥러닝 모델 규모가 커지면서 개발·학습·추론의 주된 제약이 연산량보다 **메모리 용량과 대역폭**으로 옮겨가고 있다
(이른바 memory wall). 개인 연구자, 학생, 소규모 팀은 제한된 GPU/RAM에서 반복적인 OOM(Out-of-Memory) 시행착오를 겪는다.

## 내용

### 프로젝트명의 의미
`memopro` = memory + pro(효율·전문성). 이름 자체가 다음 세 목표를 담는다.

| # | 목표 (원문 요지) |
|---|---|
| G1 | 인공지능·딥러닝의 개발, 학습, 활용 등 **모든 단계에서 메모리 부담을 최소화**한다. |
| G2 | 메모리를 극한으로 효율적으로 활용하여 **이전보다 더 작은 메모리 환경에서 구동**이 가능하게 한다. |
| G3 | 메모리의 **하드웨어 병목 현상을 극복**한다. |

### 형태와 배포 목표
- Rust 코어 + Python 바인딩의 라이브러리.
- 최종 목표: **crates.io 와 PyPI 양쪽 배포**.
- 채택 구조: Cargo workspace + PyO3 + maturin (한 코드베이스 → 두 레지스트리).

### 대상 사용자
개인 연구자·학생(단일 소비자 GPU), 추론 비용을 줄이려는 서비스 개발자, 엣지·노트북 환경 개발자,
메모리 최적화 기능이 필요한 다른 라이브러리 제작자.

## 실험 환경 (개발 기기)

| 항목 | 값 |
|---|---|
| 하드웨어 | MacBook Air (MacBookAir10,1), Apple M1, 8코어(4P+4E), **8GB 통합 메모리** |
| OS | macOS 26.6.2 (25G83) |
| Rust | rustc 1.98.1 / cargo 1.98.1 |
| Python | 3.14.0 (PyTorch 미설치, maturin 미설치 — 착수 시점) |

> 개발 기기 자체가 8GB 통합 메모리의 **저메모리 환경**이다. G2 검증의 실제 테스트베드로 활용할 수 있으며,
> CUDA 분리 메모리 환경과의 비교(RQ3)는 별도 GPU 환경이 필요하다.
