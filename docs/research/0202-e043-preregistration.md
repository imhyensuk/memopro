## 예상 (미리 계산)

- 3B(5.75GiB)와 DINOv2(4.2GiB)는 T4에서 캐시에 전부 들어간다(auto ≈ 12GiB). 첫 사용 뒤로는 복사가 없다.
  - 3B: 첫 복사 약 2초를 토큰 64개에 나누면 약 0.03초/토큰. 훅 비용을 더하면 약 0.1~0.15초/토큰.
  - DINOv2: 둘째 실행은 복사 없음.
- 7B(14.2GiB)는 약 12GiB가 캐시에 남는다. 토큰마다 나머지 약 2.2GiB를 호스트에서 복사(호스트 예산 6GiB 안이므로 디스크 읽기 없음)하므로 약 0.5~1초/토큰.

## 기준 (자동 판정 `S-모델`)

| # | 기준 |
|---|---|
| **S-3B** | 생성 글이 그냥 실행과 같고, s/token ≤ 그냥 실행의 2배 |
| **S-7B** | 생성 글이 그냥 실행과 같고, s/token ≤ **2.0초**(캐시 없는 1차의 약 20분의 1) |
| **S-DINOv2** | 출력 해시가 그냥 실행과 같고, 둘째 실행 시간 ≤ 그냥 실행의 2배 |
