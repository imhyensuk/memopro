## 바꾼 것과 그대로인 것

- **그대로**
  - 대상: Qwen2.5-3B bf16, MPS, 예산 1GiB.
  - 프롬프트 4개 × 64토큰, 탐욕. 경우 P/S15/S3.
  - 환경 변수, 경우마다 새 프로세스, 스왑 오염 규칙, footprint 지표, 판정 코드(`summarize`)와 기준 X1·X2·X3.
  - P는 일반 `model.generate`(기준).
- **바뀐 것**
  - S15·S3는 `memopro.rt.torch.generate(model, ids, draft=...)`로 생성한다(0142).
  - 실행기: `experiments/e033b_spec_decode_rows/run.py`. E033과의 차이는 이 호출, 결과 경로, 문서 문자열뿐이다.
- **시작 상태**(실행 전 확인)
  - 시스템 스왑 사용 4,080MiB(이전 작업이 남김), 시스템 여유 메모리 68%.
  - 다른 앱(Claude, Chrome)이 열려 있다. Claude Code는 다른 앱을 닫지 않는다.
- **개발 확인**(0142, 결과 아님): 프롬프트 1·2에서 E033 P와 같은 토큰.

## 기준 (E033과 같다)

| # | 기준 |
|---|---|
| **X1** 출력 동일 | 4개 프롬프트 모두 S15의 64토큰이 P와 같다 |
| **X2** 속도 | S15 토큰당 시간 ≤ P의 1/2.5 |
| **X3** 메모리 | S15 footprint 증가 ≤ 예산 + 초안 + 512MiB 그리고 ≤ 2,943MiB, 시스템 스왑 증가 ≤ 64MiB(오염 규칙 뒤), 런타임 최대 계상 ≤ 한도 |

- 관문 G4-E4 = X1·X2·X3. 실패하면 멈추고 보고한다.
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e033b_spec_decode_rows.run --all`. 결과는 `docs/research/data/e033b/`.
