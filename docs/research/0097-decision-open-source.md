# 0097. 결정: memopro는 무료 오픈소스로 배포한다(MIT OR Apache-2.0 유지), 수익화는 나중에 오픈 코어로만 검토

- **날짜**: 2026-09-29
- **유형**: decision (사용자 결정)
- **상태**: 확정
- **관련 기록**: 0010 (두 층, 기존 기술 재구현 금지), 0012 (대상 사용자), 0033 (논문 A·B), 0086 (E010), 0095 (객관 평가)

## 배경

사용자가 무료 오픈소스 배포와 서비스 형태의 수익화 가운데 어느 쪽이 나은지 물었다. 분석을 받은 뒤 이렇게 정했다.

> "오픈소스로 결정할게, 연구 기록으로 남겨줘."

## 고려한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 무료 오픈소스(허용형 라이선스) | 사용자와 수요 데이터를 가장 싸게 모은다. 논문 재현성과 인용에 유리하다. 사용자 프로세스 안에서 도는 라이브러리라는 형태에 맞는다 | 직접 수익이 없다 |
| B. 서비스(SaaS) | 수익 구조가 분명하다 | 목적과 충돌한다. memopro의 가치는 **사용자 자기 기기의 적은 메모리**로 큰 모델을 쓰는 데 있는데, 서버에서 대신 돌리면 클라우드 GPU 대여 사업이 된다 |
| C. 비공개 유료 라이브러리 | 코드를 보호한다 | PyTorch 개발자는 자기 프로세스 안의 비공개 바이너리를 잘 쓰지 않는다. 대체재(accelerate, bitsandbytes, llama.cpp, Ollama, MLX 등)가 무료다 |
| D. 오픈 코어(핵심 무료 + 팀/기업 부가 기능 유료) | A의 장점을 유지하면서 나중에 수익 여지가 있다 | 사용자가 먼저 있어야 성립한다 |

## 결정

- **A를 택한다.** 저장소에 이미 선언된 `MIT OR Apache-2.0`(`Cargo.toml`, `pyproject.toml`, `LICENSE-MIT`, `LICENSE-APACHE`)을 그대로 쓴다.
- **D(오픈 코어)는 나중의 선택지로만 남긴다.** 사용자, 특히 팀이나 기업 사용자가 실제로 보일 때 새 결정 기록으로 연다.
  - 후보 예: CI의 메모리 회귀 검사(`check`), 여러 장비의 census 결과 대시보드, 기술 지원.
- **B와 C는 택하지 않는다.**

## 근거

1. **형태**: 사용자 기기에서 도는 라이브러리이고, 서비스로 바꾸면 목적이 사라진다(선택지 B의 단점).
2. **경쟁**: 접근 계층은 설계상 무료 기술을 묶어 쓴다(0010). 기존 도구와 비교해 새 능력이 없고, 가치는 자동화·안전·정확성에 있다(0095). 돈을 받을 만한 차이가 아직 증명되지 않았다.
3. **증거**: 0095 평가는 가중 약 53%, 증명된 가치는 약 35%(0090)였다. E010 수요 데이터도 아직 없다. 공개 배포가 사용자와 데이터를 모으는 가장 싼 길이다.
4. **대상 사용자**: 메모리가 적은 장비를 쓰는 개인 개발자와 학생이라 지불 능력이 낮다(0012).
5. **연구**: 논문 A(census)와 논문 B(도구 논문)는 코드가 공개되어 재현할 수 있어야 평가와 인용에 유리하다(0033).

## 이 결정으로 바뀌지 않는 것

- **배포 행위 자체는 여전히 사용자의 명시적 확인이 필요하다.** PyPI·crates.io 게시와 릴리스 태그 push는 확인 뒤에만 한다.
- 저장소 공개(private → public) 시점도 따로 정한다.
- 공개 전 확인 사항(권고, 사용자 판단)
  - **저작권 관리**: 나중에 D를 열 여지를 남기려면 외부 기여를 받을 때 CLA(기여자 라이선스 동의)를 받는다. 이미 공개한 코드는 MIT/Apache로 계속 남는다.
  - **소속 기관 규정**: 기관 소속으로 개발했다면 교내 지식재산 규정에서 공개 권한을 확인한다.
  - **시점**: E022 재측정(0098)과 E010 뒤를 권한다. 패키지 이름 선점은 별도 결정이다.

## 논문 매핑

- **논문 B(도구 논문)**: 가용성 문단("MIT OR Apache-2.0으로 공개"), 재현 패키지. 서지 필드는 공개 시점에 채운다.
- **논문 A**: 데이터·코드 공개 문단의 근거.
