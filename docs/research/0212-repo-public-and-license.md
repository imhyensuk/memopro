# 0212. 저장소 공개와 라이선스 검토

- **날짜**: 2026-10-06
- **유형**: decision (사용자 지시) + 검토 (제안)
- **상태**: 공개 확정. 라이선스는 바꾸지 않는 것을 제안(사용자 결정 대기)
- **관련 기록**: 0097 (MIT OR Apache-2.0), 0153 (배포 준비), 0210·0211 (논문)

## 공개

- 사용자 지시: "공개해" (2026-10-06). `gh repo edit --visibility public`으로 `imhyensuk/memopro`를 공개했다.
- 공개 전 점검(같은 날): 커밋 기록 전체에 비밀값(토큰·개인 키) 없음, 5MB 넘는 파일 없음, 라이선스 파일 둘, E010 참가자 데이터 없음, 포크 PR이 비밀값에 닿는 작업 흐름 없음. 커밋 작성자 이메일과 로컬 경로는 공개된다.
- PyPI·crates.io 게시는 별개다. 여전히 사용자 확인 뒤에만 한다.
- JOSS의 "공개 6개월" 조건은 이날부터 센다(빨라야 2027-04).

## 라이선스 검토: "독창성을 지키려면 라이선스를 바꿔야 하나"

- **라이선스가 지키는 것은 코드의 저작권이지 아이디어가 아니다.** 어떤 라이선스든 남이 같은 방법을 다시 구현하는 것은 막지 못한다. 아이디어를 막는 제도는 특허다.
- **학술적 독창성(먼저 했다는 사실)은 공개 시점과 인용으로 지킨다.** 공개 저장소의 커밋 기록, arXiv 프리프린트, 학회 논문이 우선권의 증거다. 인용을 받으려면 CITATION.cff를 둔다.
- 선택지:

| 선택 | 효과 | 비용 |
|---|---|---|
| A. 그대로 MIT OR Apache-2.0 (제안) | 쓰는 사람이 가장 많다. Apache-2.0의 저작자 표시·특허 조항 | 남이 고쳐서 닫힌 제품에 넣을 수 있다 |
| B. GPL-3.0 / AGPL-3.0 | 고친 판을 배포(AGPL은 서비스 제공 포함)하면 소스를 공개해야 한다 | 기업·다른 라이브러리가 덜 쓴다. 0097(자유 오픈 소스, 허용적) 결정을 바꾸는 일 |
| C. 비상업 라이선스(CC BY-NC, PolyForm 등) | 상업 이용 금지 | OSI 오픈 소스가 아니게 된다 → JOSS 불가, PyPI 이용자 감소. 0097과 충돌 |

- **바꿔도 과거판은 그대로다.** 이미 MIT/Apache로 공개된 커밋은 그 조건으로 계속 쓸 수 있다. 바꾸면 이후 판에만 적용된다.
- **특허**: 공개로 이 저장소의 내용은 공지된 기술이 되었다. 한국·미국에는 공개 후 12개월 안의 공지 예외(유예) 제도가 있으나 유럽 등에는 없다. 특허를 원하면 이 기간 안에 따로 판단해야 한다(이 기록은 법률 자문이 아니다).
- **제안**: A 유지 + CITATION.cff 추가 + 논문 투고 전 arXiv 프리프린트로 우선권 남기기.
