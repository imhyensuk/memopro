# 0015. 개선 제안 P1~P4 채택: 실험 우선, 범위 축소, OS 기준선, 명시 실행

- **날짜**: 2026-09-25
- **유형**: decision
- **상태**: 확정 — 설계 v0.3.2에 반영
- **관련 기록**: 0014 (제안), 0012·0013 (설계 v0.3.1)

## 사용자 결정

> "P1~P4를 채택하고 S1 기반 구축과 첫 실험까지 전부 진행해."

| 제안 | 결정 | 설계 반영 |
|---|---|---|
| P1 실험 먼저 | ✅ | 개발 순서: S1 → **첫 실험(X1)** → A1 → N1. X1 = α E001~E003, 텐서 중복도 파일럿 E005, 노트북 유휴 계측 도구 E006 |
| P2 범위 축소 + 걷는 뼈대 | ✅ | S1에서 빌드 → wheel → 설치를 끝까지 관통(배포는 사용자 확인 후). v0.1에서 census 정밀 모드는 v0.2로, 한국어 문서는 v0.1.x로, wheel은 macOS arm64·Linux x86_64 우선 |
| P3 OS 기준선 | ✅ | β 우선 환경 = CUDA VRAM, 스왑 없는 환경. CPU 텐서(스왑 있는 환경)는 OS 스왑·압축 대비 이득을 측정한 뒤에 주장. 모든 β 평가에 OS 기준선 포함 |
| P4 명시 실행 기본 | ✅ | β 기본 동작 = census가 유휴 객체와 회수 가능량을 제안 → 사용자가 `%hibernate <이름>`으로 실행. 자동 모드는 선택(`auto=True`) |
| P5~P10 | 보류 | 구현 단계에서 재검토 |

## S1 진행 중 함께 적용한 기본값 (0008 권고안, 변경 가능)

S1 기반 구축에 필요한 미결정 항목은 이전에 제시한 권고안을 적용한다. 사용자는 언제든 바꿀 수 있다.

| 항목 | 적용값 | 비고 |
|---|---|---|
| 라이선스 | MIT OR Apache-2.0 | 저작권자 표기는 "memopro contributors" (개인 이름을 추정하지 않음) |
| 최소 Python | 3.10 (abi3-py310) | 개발 환경은 3.14 |
| GitHub 위치 | 미정 | 원격 저장소 없이 로컬 git만 사용. CI 설정 파일은 작성하되 실행은 원격 연결 후 |
| 이름 선점 0.0.1 배포 | **하지 않음** | 공개 배포는 사용자의 명시적 확인이 필요 |
