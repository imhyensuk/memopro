# 0183. E041 사전 등록: 예산이 전부를 덮는가 — 초안 붙은 생성(3B·7B), 2,048토큰 학습(3B·7B)

- **날짜**: 2026-10-05
- **유형**: experiment (사전 등록)
- **상태**: 확정. 실행 전
- **관련 기록**: 0182 (생성 덜어 두기), 0168·0169 (E037c: 512토큰), 0174 (E038b), 0179 (채점표 A12·A13)

## 경우 (각각 새 프로세스, E037c의 측정과 스왑 오염 규칙)

| 이름 | 무엇 | 모델 | 예산 |
|---|---|---|---|
| G3 | `memopro.generate` + 1.5B int4 초안, 프롬프트 2개 × 32토큰 | Qwen2.5-3B | 2GiB |
| G7 | 같음 | Qwen2.5-7B(리비전 고정) | 3GiB |
| RG7 | 같음 (거절 확인) | 7B | 2GiB |
| T3a / T3b | `memopro.finetune(seq_len=2048)`, WikiText 2,047토큰 × 5 = 5단계 | 3B | 2.5GiB / 2.25GiB |
| T7a / T7b | 같음 | 7B | 3.75GiB / 3.5GiB |

- **미리 계산한 값**(라이브러리 함수, 개발 확인)
  - 2,048토큰 학습 몫: 3B 1,446MiB, 7B 2,304MiB. 가장 큰 가중치(3B 593, 7B 1,039)를 더하면 3B ≥ 2,039, 7B ≥ 3,343MiB → 모든 학습 경우는 시작한다.
  - 생성 몫(초안 1,226MiB 포함): 3B 1,244, 7B 1,254MiB → G3 ≥ 1,837, G7 ≥ 2,293MiB. RG7(2,048)은 거절되어야 한다.
- 프롬프트는 E033b의 앞 두 개, 채팅 템플릿.
- **기준 출력**: 같은 프롬프트의 일반 탐욕 생성 토큰. 3B는 E033c P, 7B는 E038b P에서 앞 32토큰을 쓴다(끝 토큰에서 자름).
- 환경: E037c와 같다(`MallocLargeCache=0`, 오프라인, 워터마크는 라이브러리 기본).
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e041_budget_all.run --all`. 결과는 `docs/research/data/e041/`.

## 기준

| # | 기준 |
|---|---|
| **K1** | G3·G7의 글이 일반 탐욕 생성과 같다. 단, 끝 토큰에서 멈춰 앞부분만 같은 경우도 같다고 본다(기준 출력은 끝 토큰을 막고 만들었다) |
