## 채점표에 아직 반영되지 않은 것

- **Colab 재실행이 끝나면 바뀔 수 있는 조건**
  - A14·U16(CUDA에서 LoRA까지): torchao 충돌을 고친 LoRA 재측정 대기.
  - A16(7B 무손실 생성 ≤ 1초/토큰): GPU 캐시 뒤 T4에서 예상 0.5~1초/토큰(E043).
  - 셋 다 충족하면 비교 포함 53.4%, 비교 제외 58.8%.
- **`adopt`(범용 맡기기 API)**: macOS에서 명시적 API로 데이터 세 묶음을 예산 안에 두고 결과를 그대로 지켰다(E045).
  - 그러나 B12 조건("macOS에서 Linux와 같은 작업")은 E040의 같은 프로그램으로 재야 한다. E045는 다른 작업이라 세지 않았다.
  - 같은 작업(pandas 열 등)을 `adopt`로 다시 재면 B12를 판정할 수 있다.
- **측정 연구 결과**: KV 캐시와 가중치의 무손실 정보량이 같다(E044). 논문 근거는 늘었지만 채점 조건(D4~D7: 논문 초안·제출)은 그대로다.

## 판단

- **핵심 기능은 탄탄하다.** 8GB에서 7B 16비트 학습·무손실 생성, 예산 상한, 결과 동일성이 측정으로 반복 확인됐다.
- **CUDA와 범용 데이터 작업으로 넓히는 중**이다. 정확성은 모든 경우에서 지켜졌다.
- **반복해서 드러난 약점은 속도**다.
  - 흘려 쓰기 생성은 메모리 밖이면 느리다(CUDA 1차 41~47초/토큰, 개선 대기).
  - 무작위 접근 데이터와 bf16 KV는 무손실 압축의 이득이 작다.
- **점수를 가장 크게 움직일 일**
  1. Colab 재실행 결과(조건 셋)
  2. 공개 배포(제품 조건 넷)
  3. 논문 초안(연구 조건 넷)
  - 2와 3은 사용자 쪽 결정이 필요하다.
