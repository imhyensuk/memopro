## 요지

- **무엇을 관리하나**: 런타임이 만들었거나 등록된 큰 버퍼. 바이트만 알고 형식은 모른다(P1). 소유 형태는 Owned(런타임 아레나)와 Borrowed(예: torch 저장공간).
- **다섯 행동**: 두기 / 압축 / 원본 재읽기 / 재계산 / SSD 이동. 모두 **무손실**이고 비트 단위로 되돌린다(R1).
  - 원본 재읽기는 다이제스트로 확인한다.
  - 재계산은 결정성 표시가 있거나 첫 결과를 확인한 뒤에만 쓴다.
- **만드는 법(recipe)**: `Source`(파일 구간 + 다이제스트), `Lineage`(입력 버퍼 + 등록된 계산 함수, DAG), `Seed`.
- **상태 기계**
  - 상주
  - 사용 중(pin, 절대 옮기지 않음)
  - 압축
  - 원본으로 버림
  - 계보로 버림
  - 방출
  - 파일 기반(OS가 쓰기 없이 회수, 0072)
  - 장치 버퍼는 호스트 내리기 단계가 하나 더 있다.
- **상한 보장(R2)**: 새 할당 전에 입장 제어로 지킨다. 내보낼 것이 없으면 거절하고 제안한다.
- **선택 점수**: 예상 정체 시간 / 풀리는 바이트. DTR·Capuchin 계열 점수를 다섯 행동으로 일반화한 것이다(0108). 비용은 이 기기의 실측이다(R3). 초기값은 과거 실험 값을 쓴다:
  - 재읽기 0.74 대 0.28 GB/s(E015).
  - 복원 1.28 대 OS 3.86초(E011).
  - 할당기 낭비(0060, 0080, 0105).
- **안전(R4)**: 백그라운드 서비스 스레드 하나와 입출력 작업자 풀은 **런타임 소유 메모리만** 만진다. 사용자 텐서 교체는 안전 지점에서만 한다(γ 규칙과 β 가드 유지).
- **전용 할당기(`rt::arena`)**: 관리 버퍼에서 할당기 낭비(MPS 1GiB 힙, CUDA 조각, libmalloc 캐시)를 없앤다. 버린 영역은 즉시 OS에 돌려준다.
- **플랫폼**: Linux는 3단계에서 `userfaultfd` 투명 모드, macOS는 명시적 핸들(0108: userfaultfd 없음).
- **인터페이스**: Rust `Runtime`/`Pinned` 가드, C ABI `mp_*`, Python `memopro.rt`.
  - NumPy는 고정 중 무복사 뷰를 쓴다.
  - PyTorch는 `frombuffer`/DLPack과 안전 지점의 `tensor.data` 교체를 쓴다.
  - 접근 계층(`load`, `train_session`)은 2단계에서 이 층을 쓴다.
- **불변식 I1~I7**: 상한, 사용 중 불변, 복원 경로 확인, 왕복 비트 동일, 재계산 결정성, 백그라운드는 Borrowed 금지, fail-open. 각각 시험 방법을 정했다.
- **기존 코드 재사용**
  - `spill`: `Source`, `Spilled`.
  - `codec`: 압축.
  - `ledger`: 상태 표로 확장.
  - `residency`: `FileBacked`, MPS.
  - 예산: 0059, 0099~0103.
  - β 가드: 0048·0049.
  - 접근 계층 전체.

## 새로 정한 원칙 (runtime.md §1)

- R1 무손실 기본.
- R2 상한 보장(입장 제어).
- R3 실측 비용.
- R4 소유권으로 안전.
- R5 되돌릴 길 없이는 버리지 않음.
- R6 예측과 보고.
- R7 플랫폼 정직성.
- R8 fail-open(데이터가 틀릴 수 있으면 오류).
- RS1~RS5는 유지한다.

## 결정 필요 (사용자)

1. **RS7 해제**: 런타임 서비스 스레드 하나(GIL 무관)를 R4·I6 안전 규칙과 함께 허용한다. RS6·RS8은 계속 보류한다.
2. **1단계 대표 비AI 작업**: (a) 큰 배열 파이프라인, (b) 이미지 묶음 처리, (c) 데이터프레임 열 집계, 또는 사용자의 실제 사례.
3. **이름**: `memopro.rt` / `memopro::rt` / `mp_`.
4. **E025(G-R1) 사전 등록 후 1단계 착수.**

## 범위 밖 (정직하게 적음)

- 동시 작업 집합이 예산보다 큰 작업: 불가능하다고 실행 전에 알린다.
- 계보를 모르는 임의 메모리의 재계산: 하지 않는다.
- 손실 방법의 자동 적용: 하지 않는다(접근 계층의 `quality`가 맡는다).
