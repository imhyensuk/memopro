# 0007. "완전히 새로운 기법"의 가능성 검토와 관찰 우선 방법론

- **날짜**: 2026-09-24
- **유형**: survey + decision(방법론)
- **상태**: 확정 (검토) / 방법론 채택은 사용자 승인 대기
- **관련 기록**: 0006

## 배경 / 동기

사용자 질문: "완전히 새로운 것을 생각해볼 수 있겠는가?"
0006까지 아이디어 12개 중 9개가 기존 연구와 겹쳤다. 이번에는 더 급진적인 발상(유휴 하드웨어 전용, 다른 분야 개념 차용)을 시도하고,
그 결과로부터 "완전한 신규성"을 얻는 현실적인 방법을 검토한다.

## 급진적 아이디어 검증

| 아이디어 | 발상 | 결과 |
|---|---|---|
| GPU 텍스처 압축 하드웨어(ASTC/BC)로 가중치 저장 | 그래픽용 하드웨어 디코더를 ML에 전용 | 🔴 선행 있음 — ARM, "Compressing Deep Neural Networks with ASTC"(2017, AlexNet 240MB → 27MB) |
| 비디오 코덱 하드웨어(H.264/265)로 텐서 압축 | 학습 중 노는 미디어 엔진 활용, 층·토큰 간 중복을 영상 프레임 간 중복처럼 처리 | 🔴 선행 있음 — LLM.265/VcLLM (MICRO 2025), LLMCodec(2026), 미디어 ASIC 기반 프리픽스 전송(2026) |
| Apple GPU 손실 텍스처 압축(A15/M2 이상, 1:2 고정 비율)으로 활성값·KV 캐시 저장 | Metal의 투명한 하드웨어 압축 전용 | 🟡 직접 사례 미발견. 단 ASTC 선례가 있어 학술 신규성은 약하고, **개발 기기 M1은 이 기능이 없어** 검증 불가 |
| 가중치 유사역행렬로 선형층 입력 역산 | `h = W x`에서 W가 확장형(d → 4d)이면 x를 h로부터 정확히 복원 가능 | ⚫ **계산 결과 폐기** — h에서 x를 복원하는 비용(행렬곱 1회)과 x에서 h를 재계산하는 비용이 같고, x가 더 작다. 기존 재계산 방식이 항상 우월하다 |
| 중첩(홀로그래픽) 체크포인트 | L개 층의 활성값을 시드 기반 무작위 직교 키로 하나의 버퍼에 중첩 저장, 역전파 때 키로 분리 후 α의 고정점 교정 | ⚫ **계산 결과 폐기** — 분리 시 다른 층들이 만드는 잡음 노름 ≈ √(L−1)·‖x‖. GPT-2(L=12)면 잡음이 신호의 약 3.3배. 4비트 양자화(상대 오차 약 6%) 수준 이하로 내리려면 압축이 사실상 불가능. 밀집(dense) 활성값에서는 양자화가 항상 우월하다. 희소 데이터에서만 성립 여지가 있음(압축 센싱) |
| 근사 활성값 저장 역전파 | — | 🔴 선행 있음 — "Backprop with Approximate Activations"(2019) |

## 관찰

1. **"안 쓰는 하드웨어를 활용하자"는 급진적 발상조차 이미 논문이 있다** (텍스처 유닛, 비디오 엔진).
   이 분야는 매우 붐비며, 책상 위 발상만으로 완전한 신규성을 얻을 확률은 낮다.
2. 아이디어를 내는 쪽(Claude)은 기존 문헌을 학습한 모델이라, 발상이 **기존 개념의 재조합** 쪽으로 기운다.
   재조합과 빠른 선행 조사는 강점이지만, "선례 없음"을 보장할 수는 없다.
3. 간단한 계산(역산 비용 비교, 중첩 잡음의 신호 대 잡음비)만으로 2개 아이디어를 조기에 폐기했다.
   → 실험 전 **간단한 계산 검증을 기본 절차**로 삼는다.

## 이 분야의 "새로운 것"은 어디서 왔나

| 사례 | 새로움의 원천 |
|---|---|
| LLM.int8() | **실측에서 발견한 현상**: 특정 차원에 극단적 이상치(outlier)가 존재 |
| FlashAttention | **관점 전환**: 연산량이 아니라 메모리 입출력(IO)이 병목 |
| PagedAttention(vLLM) | **다른 분야 개념 차용**: OS 가상 메모리의 페이징 |
| LLM.265 | **다른 분야 하드웨어 차용**: 비디오 코덱 |

→ 차용형(3, 4번 행)은 이미 많이 소진되었다. 반면 **실측으로 새 현상을 발견하는 경로(1번 행)**는 모델, 설정, 하드웨어가 바뀔 때마다 새로 열린다.

## 결정 (제안): 관찰 우선 방법론 (Observation-first)

발상 → 조사를 반복하는 대신, **실제 학습을 계측해 아직 보고되지 않은 메모리 중복성을 찾는다.**

### 메모리 정보 센서스 (Memory Information Census) — 계측 항목 초안

M1 8GB에서 GPT-2 small 파인튜닝을 돌리며, 역전파용으로 저장되는 모든 텐서(`saved_tensors_hooks`)와
옵티마이저 상태에 대해 다음을 측정한다.

1. **실제 정보량**: 텐서별 경험적 엔트로피(비트/원소) 대비 저장 비트수 → "낭비 비트" 지도
2. **그래디언트 민감도**: 각 저장 텐서에 비트 단위 교란을 주었을 때 그래디언트가 변하는 정도 → "역전파가 실제로 필요로 하는 비트수"
3. **층 간 상관**: 인접 층 저장 텐서 간 상호정보·상관
4. **시간적 중복**: 같은 파라미터의 옵티마이저 상태가 스텝 간 얼마나 변하는가
5. **생애 주기**: 텐서별 생성 → 마지막 사용까지의 시간, 유휴 구간

결과가 곧 **측정 연구(measurement study)** 논문의 재료가 된다. 예상 밖의 구조가 나오면 그것이 새 기법의 출발점이 된다.
α(잔차 고정점 체크포인팅)의 가설 H1~H3 검증과 **같은 실험 환경**을 공유하므로 추가 비용이 작다.

## 한계

- 신규성 판정은 웹 검색 수준이다.
- 중첩 체크포인트의 폐기 근거는 밀집 활성값 가정에 기반한다. 희소 활성값(ReLU 계열 등)에서는 재검토 여지가 있다.
