# 0173. E038b 사전 등록: 7B 무손실 생성을 1.5GiB 예산으로 — E038과 같은 기준

- **날짜**: 2026-10-05
- **유형**: experiment (사전 등록)
- **상태**: 확정. 실행 전
- **관련 기록**: 0172 (E038 결과, 선택지), 0171 (E038 사전 등록)

## 사용자 결정

0172의 선택지 중 **A. 예산을 1.5GiB로 줄여 재측정**(2026-10-05).

## 바꾼 것과 그대로인 것

- **바뀐 것**: 7B의 가중치 예산 2GiB → **1.5GiB**(한도 1,531MiB). 실행기 `experiments/e038b_7b_generation/run.py`(E038과는 예산·결과 경로·문서 문자열만 다름), 결과 `docs/research/data/e038b/`.
- **등록 전 확인**
  - 가장 큰 가중치(임베딩·출력 머리 각 1,039MiB)가 한도에 들어간다.
  - 행 불변 검증은 층 하나(약 466MB)를 고정하고, 출력 머리는 따로 고정된다.
  - 생성은 학습처럼 활성값을 떼어 두지 않는다(`hold_back`은 `finetune` 전용).
- **그대로**: 경우 P·S15, 프롬프트 2 × 32토큰, 환경, 오염 규칙, 판정 코드, 기준.

## 기준

| # | 기준 |
|---|---|
| **X1** | 두 프롬프트 모두 S15의 32토큰이 P와 같다 |
| **X2** | S15 토큰당 시간 ≤ P의 1/2.5 |
| **X3** | S15 footprint 증가 ≤ 예산 + 초안 + 512MiB(3,274MiB), 그리고 ≤ 7B 절반(7,263MiB). 스왑 증가 ≤ 64MiB(오염 규칙 뒤), 런타임 최대 ≤ 한도 |

- 실패하면 멈추고 보고한다.
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e038b_7b_generation.run --all`

## 논문 매핑
