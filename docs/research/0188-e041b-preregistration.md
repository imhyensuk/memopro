## 바꾼 것

- 라이브러리: 0187(어텐션 점수 항, 배수 1.4).
- 실행기 `experiments/e041b_budget_all/run.py`(E041 복사). 경우와 판정만 아래처럼 바꿨다. 측정 방법, 환경, 스왑 오염 규칙은 E041과 같다.

| 이름 | 무엇 | 모델 | 예산 | 비고 |
|---|---|---|---|---|
| G3 / G7 / RG7 | E041과 같음 | 3B / 7B / 7B | 2 / 3 / 2GiB | |
| T3a / T3b | `finetune(seq_len=2048)` 5단계 | 3B | 3 / 2.75GiB | 필요 ≥ 2,663MiB |
| T7a / T7b | `finetune(seq_len=1024)` 5단계 | 7B | 2.75 / 2.5GiB | 필요 ≥ 2,454MiB. **표본 밖 점** |
| RT7 | `finetune(seq_len=2048)` | 7B | 3.75GiB | 필요 ≥ 4,448MiB → 시작 전 거절이어야 함 |

- 7B 2,048토큰 학습은 이 8GB 기기에서 약 4.4GiB가 필요해 재지 않는다(0187 표).
- 글: WikiText 앞부분, 경우별 길이(`texts_2048.json`, `texts_1024.json`).
- **명령**: `caffeinate -i .venv/bin/python -m experiments.e041b_budget_all.run --all`. 결과는 `docs/research/data/e041b/`.

## 기준

| # | 기준 |
|---|---|
| **K1** | G3·G7 글이 일반 탐욕 생성과 같다(끝 토큰에서 멈춘 앞부분 일치 포함) |
| **K2** | T3a/T3b, T7a/T7b가 5단계를 끝내고 손실이 유한하며 두 예산에서 비트 동일 |
| **K3** | G3·G7·T 네 경우 footprint 증가 ≤ 예산 + 256MiB, 스왑 ≤ 64MiB(오염 규칙 뒤), 런타임 최대 계상 ≤ 예산 |
